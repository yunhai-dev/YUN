## Docker Compose：定义并运行多容器应用的工具 {#news-11}

> **Docker Compose** 用于运行多容器 Docker 应用，并通过 Compose 文件定义应用中一个或多个容器的配置。用户可执行 `docker compose up` 创建并启动应用。

![Docker Compose：定义并运行多容器应用的工具](https://opengraph.githubassets.com/e5ed6e227d8510b66bfc0ed1786ecb65b2cca29331c373708ae1aef836d1eeba/docker/compose)

使用 **Docker Compose** 时，开发者可以先用 Dockerfile 定义环境，再在 `compose.yaml` 中定义服务。

在 Windows 和 macOS 上，Docker Compose 已包含于 Docker Desktop；Linux 用户可从仓库发布页面下载二进制文件。

Linux 用户需要将二进制文件安装到 Docker CLI 插件目录。Python 版本的 Compose 位于仓库的 `v1` 分支。

Docker Swarm 未采用 Compose Specification，部分较新的 Compose 语法增强功能无法供 Swarm 用户使用。

[查看原文](https://github.com/docker/compose)

## terminal-browser：可在终端运行并远程访问网络的浏览器 {#news-12}

> **terminal-browser** 是一个运行在终端中的浏览器，支持 macOS 和 Linux 安装，也可通过 SSH 将网络请求经由远程服务器执行。

![terminal-browser：可在终端运行并远程访问网络的浏览器](https://opengraph.githubassets.com/e6d5491e6c45f6bf45c790e398fc4139082e7b9d2958a45ed19f627e15e769e6/zenbu-labs/terminal-browser)

项目支持使用安装脚本或 Homebrew 安装。在 Windows 上使用 `terminal-browser` 必须通过 WSL。

用户可运行 `terminal-browser open <url>` 打开指定地址，也可以使用 `--split right` 在右侧分屏打开。

项目提供 Claude Code 插件，并支持通过兼容 `agent-browser` 的命令行界面与已打开的浏览器交互。

用户可执行 `terminal-browser upgrade` 升级到最新版本。Windows 对支持 Kitty 图形的终端存在限制。

[查看原文](https://github.com/zenbu-labs/terminal-browser)
