## MMX任务拟采集火卫一样本并于2031年返地 {#news-1}

> 日本**MMX**任务计划于2026年发射、2027年抵达火星，并尝试在低重力环境下探测火卫一。任务拟采集至少10克样本，计划于2031年送回地球。

![MMX任务拟采集火卫一样本并于2031年返地](https://spectrum.ieee.org/media-library/an-illustration-shows-a-spacecraft-near-a-lumpy-moon-and-a-large-red-planet.jpg?id=68582408&width=1245&height=700&coordinates=0%2C225%2C0%2C225)

火卫一长约27公里，被认为可能是岩石和尘埃松散聚集而成的“碎石堆”，表面重力约为地球的1/1800。

**MMX**由推进、探测和返回模块组成，并搭载由**CNES**、**DLR**与**JAXA**合作研制的`Idefix`火星车。

`Idefix`计划于2028年或2029年初从距火卫一表面约40至100米处释放，并以每秒不到1米的速度着陆。

火卫一和火卫二的起源尚未确定，相关着陆、采样及返地安排均属于预定方案，能否完成仍取决于任务执行情况。

[查看原文](https://spectrum.ieee.org/mmx-mission-to-phobos)

## Ruff：用 Rust 编写的高速 Python 检查与格式化工具 {#news-8}

> 开源项目 `ruff` 使用 Rust 编写，集成 Python 代码检查与格式化功能，项目说明称其速度比现有工具快10至100倍。

![Ruff：用 Rust 编写的高速 Python 检查与格式化工具](https://opengraph.githubassets.com/2fe59c9a85984901bdb06db5a5e265b244a4e8059d558021af2268826d5fd2bc/astral-sh/ruff)

`ruff` 支持通过 `pip` 安装，并可使用 `pyproject.toml` 配置，同时支持 Python 3.15。

该工具与 Flake8、isort 和 Black 保持可替代的兼容性，内置缓存并支持自动修复错误，例如删除未使用的导入。

`ruff` 提供超过900条内置规则，并原生重新实现包括 `flake8-bugbear` 在内的多个 Flake8 插件。

项目提供 VS Code 等编辑器的官方集成，也支持带层级和级联配置的多仓库项目，已被多个开源项目采用。

[查看原文](https://github.com/astral-sh/ruff)

## etcd：基于 Raft 的分布式可靠键值存储 {#news-11}

> **etcd** 是一个面向分布式系统关键数据的分布式可靠键值存储，项目使用 Go 编写。它通过 Raft 共识算法管理高可用的复制日志。

![etcd：基于 Raft 的分布式可靠键值存储](https://opengraph.githubassets.com/644162ab4080c8008537400298cc9d33a4a66a39d0b4761159286d19c8e1ff77/etcd-io/etcd)

etcd 提供基于 gRPC 的用户 API，并支持自动 TLS 及可选的客户端证书认证。文章称其基准性能为每秒 10,000 次写入。

该项目已用于生产环境，并经常与 Kubernetes、locksmith、vulcand 和 Doorman 等应用配合使用。

项目说明称，主分支在开发期间可能处于不稳定甚至无法运行的状态，稳定版本应查看 releases。
