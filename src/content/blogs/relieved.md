> 林花谢了春红，太匆匆。无奈朝来寒雨晚来风。
> 胭脂泪，相留醉，几时重。自是人生长恨水长东。
> ——南唐·李煜《相见欢·林花谢了春红》

今年我的感悟比以往更深刻一些。因为在工作、学习和生活中，我遇到了很多以前没有遇到过的事情，也在这个过程中重新反思了自己。很多感受说不清楚，只能借一句“自是人生长恨水长东”来概括：人生总有遗憾，像江水一样向东流去，不因人的意愿而停。

## 林花谢了春红，太匆匆

林花谢了春红，太匆匆。很多事好像刚发生，就已经过去了；很多人好像刚走近，就已经走远了。今年这些经历让我慢慢意识到，人生里的“长恨”并不只属于爱情。工作里的困、学习里的变、认知里的深、生活里的简，最后都会落到人与人的关系里，落到自己如何看自己、如何看别人上。

下面这些文字，是我对这一年的梳理。它们不一定有答案，但至少是我真实走过的痕迹。

## 欲渡黄河冰塞川

今年在工作上，我更多想到的是，自己可能还是太年轻，总有一股不甘于现状的劲。我不甘心停留在目前能做到的状态里，总是向往一些更高的山峰。但我也知道，如果一直停留在现在的工作和生活状态中，我其实做不到。

就像那句话说的，我们总是在赎回自己自由的过程里。但今年我最深刻的意识是：按部就班地工作，并不能让我真正赎回自由。我可能还是没有很多时间去做自己喜欢的事，去陶冶自己的情操。

每到夜深人静的时候，脑海里总会想未来该怎么走、现在该怎么做。但每次都被自己困住。其实我还是处于很迷茫的阶段，不知道自己下一步到底该做什么，也不清楚自己目前能做到什么程度、能做到哪些东西。

可能在当下的环境里，我陷入了舒适圈。很多时候我也明白，如果一个人长时间待在舒适圈里，其实没办法很快速地提升自己，甚至可能会不如从前。人总还是要居安思危，这是我对工作方面的感悟。

如果不满足现状，那未来可能只有一条路，就是去做自己的一番事业。但至少目前看来，这个过程会比较痛苦、比较困难。很多时候我也不知道，到底是不敢尝试，还是其他什么情况。我总是在很多事情里求一个稳重，可能只有当明确看到这个方向很有希望，或者这件事的成功率比较高的时候，我才愿意去做。

也可能是目前的状况告诉我，我个人的抗风险能力其实并不高，不足以支撑我去为那些需要大量投入的事情做一次赌博。可能我现在也赌不起。

欲渡黄河冰塞川，将登太行雪满山。不是不想渡，也不是不想登，只是眼下的冰与雪，让我必须先承认自己的处境。

## 问渠那得清如许

对于学习，这一两年里我也有一些比较深刻的感悟。

去年这个时期，我其实自学了 Rust。但随着后面模型能力越来越强，以及时间、精力有限，更多精力其实放到了宏观上的了解，不会像之前一样做很精细化的了解，比如某一个协议到底是怎么做的，某一个算法到底是怎么做的。

现在反而更专注于业务架构方向。更多考虑的是：做这个事情，我到底应该准备哪些东西？需要怎么做一个总体框架性的设计和实现。到现在，其实很少会去细节地关心具体在 coding 层面应该怎么做。

目前来说，至少我 90% 的 coding，可能远不止 90%，都是由 Agent 帮我完成的。这其实也是一个机会。对我个人来说，它提效了很多东西，把之前大量重复性的编码工作全都释放开了。现在我更多是在架构层面有更多时间去学习探索，也有了更深层次的一些思考。

在这个过程中，我也了解到很多前沿模型在某些能力上的欠缺，以及我该怎么用好它，去做成一件事情。但这也产生了我另一个方向的恐惧情绪：因为很多底层的东西，可能在这个过程中会渐渐被遗忘。甚至以前学习中很熟练的东西，当我渐渐不去关注这些底层实现时，会逐渐生疏，甚至遗忘。

我会觉得遗忘是一件很可怕的事情。毕竟这些知识在之前是完全刻在我脑子里的，我闭着眼睛都能敲出来。但现在我还真不一定能记得之前是怎么写的。

但在这个过程中留下来的东西，其实是我的 coding 思维。我之前编码的条理性或者逻辑性，反向映射到了其他做事方式上。这就让我在做很多事情，包括与人相处上，可能都会显得过于机械、过于现实。因为很多时候，在 coding 的过程中，过程往往并不是那么重要。包括我个人也认为，做事应该以结果为导向。中间到底踩了多少坑、花了多少时间，其实都不如最后的结果重要。就像那句话说的，自古成王败寇，都只是结果导向。这也是我这一年来思考了很多的东西。

这一年来，其实也拓宽了一些眼界。比如，除了原本 coding 之外的工作，我又看到了销售方面的工作，也看到了做项目、做产品、做测试、做 UI 这一方面的一些工作。其实都是在拓宽自己眼界的过程，也让我处理事情能够更得心应手。因为我对这些有基本了解，去做事情的时候，就能把很多事情组织得很有条理。这也是可能 Agent 释放了我很多精力，让我有更多时间去做这方面的了解。

问渠那得清如许？工具像一道活水，把我从重复劳动里解放出来，让我的精力流向架构、流向更宏观的思考，也流向对其他岗位的了解。但活水冲刷之后，一些原本沉在底部的底层知识，也在慢慢被冲淡。我得到了效率与视野，也开始害怕遗忘。这大概就是今年学习上最真实的矛盾。

## 世事洞明皆学问

可能之前读书的时候，并没有觉得古文、古诗，或者哲学、心理学这些东西有什么意义。但随着个人经历越来越多，阅历越来越深，发现很多东西在我当下的情况下会有很多感触。我也总能在一些诗文里找到感同身受的情绪，然后在哲学或者心理学里找到为什么会这样、产生这样的原因到底是什么。

也是在这个过程中，让我发现看事情应该从更深层次去看，不应该浮于表面。比如某个人做了某个决策，在现在的我看来，可能会从多方面去思考：他处在的环境、他身边人的状态，以及按照人性来说，他应该怎么利好自己。这都是各方面因素影响的结果。

因为我的这种思考，我会觉得人性其实有很坏的一面。但并不是说我就这样觉得这世界上没有好人。我认为好人也是有的，包括我自己也会对弱者有怜悯之心。但这些东西往往建立在利益没有冲突的情况下。如果有冲突，其实我相信绝大部分人没办法真的做好人。因为我也觉得人性是利己的。

换到工作中也是一样，其实我并不太轻易信任别人所说的话。随着经历的事情多、了解的东西多，很多人会觉得这个事情比较难、比较不好做，或者根本不可能实现。其实我一听就知道，可能单纯是这个人的懒病犯了，他觉得这事单纯比较麻烦，只是不想做而已。

世事洞明皆学问，人情练达即文章。以前读这句话，只觉得是一句老话；现在再想，才知道“洞明”和“练达”背后，是经历、是失望、是对人性复杂面的承认。看得更深之后，我并没有变得更乐观，反而更现实了一些。但我也知道，现实不等于彻底否定善意，只是我不再轻易把善意当成理所当然。

## 人间有味是清欢

对于生活，其实我觉得倒还好。因为我个人物欲很低。我对自己生活的要求，可能就是手机、电脑不卡就好，能用就行。吃饭的话，能吃饱，不求有多好，至少不要让自己饿着，其实就很满足了。穿的也是这样，只求有的穿，不会冻到自己。可能这样就比较符合我理想化的生活状态。

但其实我也一直知道，我个人在生活方面有一些至少在我看来很严重的问题。在爱情里，我会显得过于感性。

人间有味是清欢。生活本身对我来说并不复杂，清简、够用、不冻不饿，就已经很好。但人并不是只活在物质里。越是生活简单，越能看清自己在情感上的用力；越是物欲低，越显得爱情里的投入重。于是，生活这一节很短，却通向后面最长的那一段。

## 人生若只如初见

可能就是那种，我有 100 块，我就愿意给你 99 块。剩下的一块倒不是我不愿意给你，是我得留着给自己撑口饭，至少我还得活着。

但在这个过程中，我会有很多思考。可能当我切切实实感受到对方的爱、喜欢、真诚、惦记等等的时候，我觉得这都是我应该做的。可能就是我选择了她，她也选择了我，那我就应该承担起这份责任，也叫做义务。

但是如果我感受不到对方的爱、喜欢、惦记等等一些东西的时候，其实这个状态会被反噬。因为我其实想过很多，它根本的原因其实是来自于安全感的流转。可能她对我好、依赖我，或者爱我、喜欢我的时候，我会觉得我是有安全感的。至少，有一个人是选择我的。

至少目前为止到现在，我个人对于爱情上的追求，是找一个能够坚定选择我的人。因为在这个当下的社会情况下，我们每个人积累的经济，其实都是他去面对这个随时可能会变的大环境的抗风险能力，也就是安全感，是在这个世界生活安全感的来源。然后当她把这份安全感去分给另一个人的时候，另一个人也没办法给到她安全感，其实这个安全感的守恒就会被打破。

在这个过程中，我了解到很多东西。我可能会去看星座，会觉得她是什么什么座，我是什么什么座，是不是因为两个星座怎么样。然后到后来，我可能会去看，比如她可能是什么人格，我可能是什么人格，比如说什么焦虑型或者回避型这些东西。但最后我看到的一个结果，其实都有两面。可能今天看这件事在这两个人身上是这种情况，但在另一个人下面又是另一种截然不同的情况。所以其实我也没办法从这些里面去判断出，到底这是什么样的情况。

就可能在这个过程中，我藏了很多自己的心事，她也藏了自己的一些心事。然后我不说，不想给她压力；她也不说，不想让对方为难。然后就在这个过程中，双方逐渐地失去了耐心、信任，等等一系列的东西。到最后，甚至都不是不喜欢不爱了，而是双方都已经累了，完全没有多余的精力再去维系这段感情。

但是在这些经历里，其实也让我思考了很多东西。可能之前由于时间太久，我会觉得人都是会变的，果然之前那些都是假的。我会去思考，那之前的那些东西到底是真的还是假的？这个人到底真的爱过我，还是压根就没有爱过我？但是现在我就不会再去思考这些东西。我会觉得，在之前幸福美满开心的那段日子里，或者那些事情里，她做的那些事情是出于本心。我愿意去相信，在那段时间里，她其实是有真心对我的。只是说换到了现在，可能因为各方面条件因素的影响下，发生了一些变化。但这应该分开讨论，就是那时是那时，现在是现在。人总不可能守着记忆活一辈子。

我也意识到，太过于赤诚的感情，其实并不是所有人都能接住。甚至于说，这世界上绝大部分的人，其实是没办法去接住真诚的。因为可能在他们的世界里，他们压根不知道真诚到底是什么东西。他们不知道真诚是什么东西，他们也不知道怎么真诚待人。所以当他们遇到真诚的时候，他们本能上会去恐惧这个事情，因为真诚意味着你要把你最隐秘的一面暴露给对方。所以很多人往往在这一步就会选择逃避，或者等等一系列的反应。

人生若只如初见，何事秋风悲画扇。初见当然好，可人和关系都要往前走。走到后来，安全感会流转，沉默会消耗，真诚会让人害怕，双方都会累。也正因为如此，我才慢慢愿意把“那时”和“现在”分开：那时她出于本心，我愿意相信；现在发生变化，也不必把过去全部判成虚假。人总不可能守着记忆活一辈子。

## 自是人生长恨水长东

今年这些事让我明白，工作里的困、学习里的变、认知里的深、生活里的简，最后都会落到人与人的关系里。我们想赎回自由，却常常困在舒适圈；我们借工具提效，也在遗忘里失去一部分底层能力；我们看得更深，于是更现实，也更难轻易相信；我们在爱情里付出真诚，却发现真诚本身也需要被接住。

那些说不出口的委屈，确实像月光下融不化的霜，沉默着渐痛。但痛过之后，我也慢慢愿意承认：那时是那时，现在是现在。过去的真心不必因为后来的变化而被全盘否定，现在的变化也不必被解释成从头到尾的虚假。

自是人生长恨水长东。长恨不会因为想通就消失，江水也不会因为遗憾就倒流。我能做的，可能只是带着这些经历继续往前走：在工作里寻找自己的稳重，在学习里保住该保住的东西，在人性里保留一点怜悯，在爱情里仍然相信真诚，但也知道真诚不是所有人都接得住。

林花谢了春红，太匆匆。无奈朝来寒雨晚来风。人生大概就是这样，一边失去，一边明白；一边长恨，一边继续向东。
