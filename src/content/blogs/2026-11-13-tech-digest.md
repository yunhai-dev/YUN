## OpenAI Whisper支持多语言识别与语音翻译 {#news-5}

> **Whisper** 是在多样化音频大型数据集上训练的通用语音识别模型，支持多语言语音识别、语音翻译和语言识别。

![OpenAI Whisper支持多语言识别与语音翻译](https://opengraph.githubassets.com/168f51d0a88822cb72209df54b5e2d1a3e7069fbe9cf233fe0bf5deb189710cd/openai/whisper)

Whisper 使用 Transformer 序列到序列模型，联合训练语音识别、语音翻译、口语语言识别和语音活动检测等任务。

项目可通过 `pip install -U openai-whisper` 安装，也可以直接从 GitHub 仓库安装。

Whisper 依赖 `ffmpeg`，项目页面列出了 Ubuntu、Debian、Arch Linux、macOS 和 Windows 的安装方式。

训练和测试使用 Python 3.9.9 与 PyTorch 1.10.1，代码预计兼容 Python 3.8 至 3.11 及较新的 PyTorch 版本；部分平台可能还需要 Rust。

[查看原文](https://github.com/openai/whisper)

Google表示，该模型还将用于代码编写、运行测试和验证代码变更，并进入Google AI Studio所有层级及`Gemini API`。

## Google发布Gemini 4 Hydrogen替代3.8 Flash {#news-9}

## uv以Rust打造统一Python包与项目管理工具 {#news-11}

## BuildKit支持缓存分发与无Root权限构建 {#news-12}

> **moby/buildkit** 是用于将源代码转换为构建产物的工具包，强调高效、可表达性和可重复性。自 Docker Engine 23.0 起，`docker build` 默认使用 Buildx 和 BuildKit。

![BuildKit支持缓存分发与无Root权限构建](https://opengraph.githubassets.com/00862dbeec7324ba494885578a7439d7338835d272414ed6196a6d611d30d4e6/moby/buildkit)

项目支持导入与导出构建缓存、嵌套构建任务调用，以及可分发的工作节点。

构建输出可保存为镜像、本地目录、Docker tarball、OCI tarball 和 containerd 镜像存储等格式。

缓存可导出至本地目录和 GitHub Actions cache、S3、Azure Blob Storage；后三者在文中标注为实验性功能。

## smolmaxxing测试老旧设备运行大语言模型能力 {#news-13}

> GitHub 项目 `smolmaxxing` 旨在测试小型或老旧设备能够运行的最大语言模型，并通过定制内核、内存优化和权重流式传输提升性能。项目称，所有性能声明均在实际硬件上测量。

![smolmaxxing测试老旧设备运行大语言模型能力](https://opengraph.githubassets.com/4dffa98a8d33f5dd0d163b0434e38a05809d91c47fa0a66c4ce84ab69cc9e3ce/hyperionaidev/smolmaxxing)

第一代 iPad Air 在越狱和仅使用 CPU 的条件下，可运行1.7B模型，速度约24至26 token/s；4B模型约10 token/s，8B和16B混合专家模型约3.5和2.6至4.5 token/s。
