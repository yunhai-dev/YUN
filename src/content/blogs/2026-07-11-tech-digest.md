## Apple 起诉 OpenAI 指控窃取硬件商业秘密 {#news-1}

> Apple 于周五在圣何塞联邦地区法院起诉 OpenAI 及其硬件负责人，指控其窃取商业秘密。

![Apple 起诉 OpenAI 指控窃取硬件商业秘密](https://media.wired.com/photos/6a51395dba309b253cb3d458/191:100/w_1280,c_limit/GettyImages-2233062347.jpg)

被指控的硬件负责人为 OpenAI 首席硬件官 **Tang Tan**，他此前在 Apple 工作 24 年，曾负责 iPhone 产品设计。

诉状称 OpenAI 招聘了超过 400 名原 Apple 员工，并鼓励离职员工携带未发布的专有技术。

Apple 同时指控 Tan 曾指导新员工规避其数据安全协议，并将机密零件带到 OpenAI 面试中。

OpenAI 去年以 65 亿美元收购由 Apple 高管创立的 **io Products**，联合创始人包括 Tan、**Jony Ive** 等。

OpenAI 发言人 **Drew Pusateri** 表示对其他公司的商业秘密不感兴趣；Apple 发言人 **Hannah Smith** 表示将捍卫团队创新成果。

上述指控为 Apple 单方面陈述，OpenAI 发言人予以否认，案件尚未经法院审理认定。

[查看原文](https://www.wired.com/story/apple-sues-openai-allegedly-stealing-ip-hardware/)

## Google 发现量子纠错可同时完成处理器持续标定 {#news-8}

> Google 表示，利用量子纠错数据可在执行计算的同时对超导量子比特进行持续标定，减少漂移对长算法的影响。

超导量子比特因个体差异需要逐一枚频，标定通常需离线完成，长时间运行会出现漂移。

Google 指出，原本用于纠错的数据可同时用于标定，从而在计算过程中持续重新校准处理器。

若该方法被验证，将有助于在长时间复杂算法中维持量子比特的低错误率。

目前尚无具体研究论文或同行评审出处公布。

[查看原文](https://arstechnica.com/science/2026/07/quantum-error-correction-can-constantly-recalibrate-a-processor/)

## GitHub 热门：NVIDIA 发布 OpenShell，面向 AI agent 的沙箱运行时 {#news-11}

![GitHub 热门：NVIDIA 发布 OpenShell，面向 AI agent 的沙箱运行时](https://opengraph.githubassets.com/795490e229c1930985eb5af4c936f430a13020a8c2fbf3f915afdd1a3d7a3c36/NVIDIA/OpenShell)

通过声明式 YAML 策略提供沙箱化执行环境，约束文件访问、数据外泄与网络活动。

以 agent 优先为设计理念，随项目附带发布 agent skills。

可通过官方脚本、PyPI（需 `uv`）或 Helm chart 部署到 Kubernetes（后者被标记为实验性，API 可能变更）。

## 腾讯云开源 CubeSandbox：面向 AI Agent 的轻量沙箱 {#news-15}

> TencentCloud/CubeSandbox 是一款面向 AI Agent 的即时并发沙箱，基于 RustVMM 与 KVM 构建，可硬件级隔离启动。

![腾讯云开源 CubeSandbox：面向 AI Agent 的轻量沙箱](https://opengraph.githubassets.com/58b3b2c2b6db428cab6089cf437032965f418c9c665cb28e89dfe1925b7f2d1c/TencentCloud/CubeSandbox)

项目兼容 E2B SDK，官方称可在 60ms 内创建硬件隔离沙箱，内存开销低于 5MB。

v0.5 引入 AutoPause/AutoResume、Terraform 一键集群部署、ARM64 原生支持与网络策略加固。

v0.4 新增凭据保险柜，Agent 调用外部 API 时密钥不进入沙箱，并提供版本矩阵与模板健康检查仪表盘。

v0.3.0 推出 CubeCoW 写时复制快照引擎，支持事件级快照与即时克隆回滚。

仓库采集时显示 9.6k Star、938 Fork、517 次 Commits，性能数据来自项目自述，未经第三方验证。

[查看原文](https://github.com/TencentCloud/CubeSandbox)

## 计算机安全先驱 Peter G. Neumann 逝世 享年 93 岁 {#news-24}

> IEEE Fellow、著名计算机科学家 Peter G. Neumann 于 5 月 17 日去世，享年 93 岁。

他在计算领域工作近 70 年，长期担任 SRI International 首席科学家。

![计算机安全先驱 Peter G. Neumann 逝世 享年 93 岁](https://spectrum.ieee.org/media-library/portrait-of-a-bearded-white-man-with-gray-hair-smiling-in-a-blue-suit-with-red-tie.jpg?id=67112656&width=1245&height=700&coordinates=0%2C187%2C0%2C188)

Neumann 1932 年出生于纽约市，1952 年曾与 Albert Einstein 共进早餐，讨论设计中简洁性的重要性。

他先后在 Harvard 和德国达姆施塔特工业大学求学，并在 Bell Labs 从事纠错编码与可生存通信工作。

1965 年他参与 Multics 项目并设计了其文件系统，包括分层目录、访问控制列表和动态分页虚拟内存段。

他在 SRI 主持 PSOS、IDES 入侵检测专家系统及 CHERI 架构等项目，并创建 ACM Risks Forum 长达 41 年。

他于 1995 年出版《Computer-Related Risks》一书，并获得 ACM SIGSAC、CRA、EPIC 等多项终身荣誉。

[查看原文](https://spectrum.ieee.org/ieee-remembers-peter-g-neumann)
