![Anthropic 开源仓库展示 Claude Skills 实现方式](https://opengraph.githubassets.com/78c5c5b43dd39c8b24e190a03114c58e6ea842dffe7bcdb56ec696a49fe1492f/anthropics/skills)

## Gitleaks 功能冻结，后续版本仅修复安全问题 {#news-13}

## macOS虚拟机借Metal路径加速LLM推理 {#news-14}

> Cua发布研究版本兼容层，旨在为macOS虚拟机客户系统解锁较新的Metal快速路径。特定基准显示，`llama.cpp`推理速度获得显著提升。

![macOS虚拟机借Metal路径加速LLM推理](https://opengraph.githubassets.com/5949ad2f8a733f6f491ef0a228764ffa23bb1adecd051023b3f8e1c012c665d1/trycua/cua)

该项目与Lume和Cua采用相同的宽松许可证，包含源代码、构建脚本、能力探针及原始基准日志。

在M1 Ultra上，TinyLlama 1.1B通过`llama.cpp`运行时，提示处理速度提升11.08倍，令牌生成速度提升16.36倍。

使用Gemma 4 12B QAT Q4_0模型时，提示处理速度提升7.20倍，令牌生成速度提升14.54倍。

作者称，相关虚拟机测试达到其裸机提示速度的较高比例，但结果仅覆盖特定芯片、模型和工作负载。

该工作仍在进一步评估不同Apple Silicon芯片、macOS版本及Metal工作负载的受益范围。

[查看原文](https://github.com/trycua/cua/blob/main/blog/gpu-passthrough-macos-vms.md)

## COMSOL 研讨会聚焦月壤建模与着陆安全 {#news-17}

> 一场免费线上研讨会将讨论利用 **COMSOL Multiphysics** 模拟月球风化层，涵盖着陆羽流相互作用与多孔风化层感应加热。

![COMSOL 研讨会聚焦月壤建模与着陆安全](https://spectrum.ieee.org/media-library/comsol-logo-with-stylized-gray-text-and-rounded-geometric-icon-on-the-left.png?id=67603988&width=980)

原文称，月球风化层受低重力、真空、颗粒不规则性、静电效应及极端热环境共同影响。

航天器着陆时，欠膨胀火箭尾焰会冲击月面，引发可压缩流动、侵蚀、颗粒喷射及潜在表面损伤。高速尘埃还可能影响能见度，并威胁宇航员和设备。

研讨会将介绍气体—颗粒耦合响应模拟，用于分析着陆点安全、侵蚀模式、喷射物轨迹和缓解策略。

感应加热部分将讨论温度相关多孔介质属性、潜热、熔融比例演化，以及恒定属性与分段属性模型的差异。原文将其对未来作业和基础设施的支持表述为潜在能力。

[查看原文](https://event.on24.com/wcc/r/5448154/155DDEC4F86810CBBC908D85D2D88569?utm_source=IEEE)

> **Microsoft**发布安全更新，修复Windows操作系统及受支持软件中的至少398个漏洞，其中包括一个已被积极利用的漏洞。

![微软更新修复近400个漏洞，含已遭利用零日](https://krebsonsecurity.com/wp-content/uploads/2026/08/workingonpc.png)

本次修复的漏洞中有42个被评为“严重”，可能让攻击者在几乎不需要用户协助的情况下远程控制Windows计算机。

本月唯一已知零日漏洞为`CVE-2026-68820`，属于Windows核心组件`afd.sys`中的权限提升漏洞。

`CVE-2026-62832`是Windows User Profile Service中的另一项权限提升漏洞，被Microsoft标记为可能已被利用。

`CVE-2026-72971`属于低影响的本地篡改漏洞，Microsoft认为其不太可能被利用。

## OpenSSH 10.5发布并欢迎AI辅助漏洞报告 {#news-20}

> **OpenSSH** 团队发布 10.5/10.5p1，并表示近期收到大量由 AI 模型发现或在 AI 辅助下发现的安全漏洞报告。团队称，相关报告仍需结合人工分诊判断实际安全影响。

OpenSSH 10.5/10.5p1 于 2026 年 8 月 11 日发布。OpenSSH 是 SSH 协议 2.0 的完整实现，并包含 `sftp` 客户端和服务器支持。

团队表示，许多 AI 报告在现实威胁模型下被判断为不具安全影响，但仍欢迎附带人工分析、测试用例或修复建议的报告。

OpenSSH 将暂时提高发布频率，以便更快向用户提供修复。便携版现在要求 `libcrypto` 支持 ECC，包括 NISTP521 曲线。

本次版本修复了 `ssh-agent`、`ssh` 和 `sshd` 的安全问题，包括代理锁定与 `session-bind@openssh.com` 扩展的交互问题。

[查看原文](https://www.openssh.org/releasenotes.html#10.5)

## 研究演示称可从主流大模型API轨迹恢复隐藏推理 {#news-21}

> 一项演示称，可从公开代理轨迹中的加密推理块恢复隐藏推理内容，覆盖 **OpenAI**、**Anthropic** 与 **Google** 的前沿模型。文中所列泄露规模及敏感信息数量尚无独立第三方验证。

![研究演示称可从主流大模型API轨迹恢复隐藏推理](https://stolen-thoughts.com/assets/fig1-extraction-fidelity.svg)

研究者称从 GitHub 和 Hugging Face 收集了6,708条公开代理轨迹，涉及 **Claude**、**GPT** 和 **Gemini**，其中仍含加密推理块。

文章称，对已签名块应用解码流程后，重建了315,320个推理块；解码内容与 API 报告的隐藏思考 token 数量密切对应。

作者称，在非基准测试的真实用户会话中恢复出704项不同隐私信息痕迹，包括62个 API 密钥、33个密码、24个访问令牌和30个个人邮箱地址。

文中称，其中64项信息仅出现在推理块中，未出现在可见会话内容。上述推理泄露与重建结果均为作者演示和声明。

[查看原文](https://stolen-thoughts.com/)
