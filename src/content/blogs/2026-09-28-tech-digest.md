## 研究显示 AI 代理参与模型开发但人类仍主导决策 {#news-1}

> 一项对 769 条模型开发任务日志的分析显示，人工智能代理提出的方法建议最多占 55%，但人类作出了超过 85% 的最终决策。

约三分之一的任务如果没有人工智能，就不会被尝试，显示 AI 代理正在扩大模型开发中的任务范围。

文章作者同时警告，代理活动增加并不意味着代理拥有更多自主权，人类仍在最终决策中占主导地位。

## GitHub 热门项目 OpenRig 用 YAML 组建多智能体团队 {#news-5}

> **OpenRig** 是一个用于同时运行 `Claude Code` 和 `Codex` 的多智能体 harness，可通过 YAML 定义智能体团队，并用一个命令启动。

![GitHub 热门项目 OpenRig 用 YAML 组建多智能体团队](https://repository-images.githubusercontent.com/1198124295/1af4015a-ccfc-48e2-9d75-81ff3f15e3a1)

该项目将多个 AI 编程代理组织为持久化团队，由主代理协调不同专业代理。

OpenRig 要求使用 Node.js 20、22 或 24，以及 `tmux`。示例使用 `rig setup --dry-run` 预览设置，再通过 `rig up` 和 `rig tui --shared` 启动及查看共享仪表板。

首次设置会写入提供商钩子和工作区信任设置。文档要求用户运行前查看本机修改并备份相关文件；示例还要求 Codex 已认证登录。

## GitHub 热门项目 scriptc：将 TS/JS 编译为原生产物 {#news-7}

> **vercel-labs/scriptc** 是一款实验性编译器，可将 TypeScript 和 JavaScript 编译为多种中间表示及原生产物。其生成的可执行文件不需要 Node.js 或 JavaScript 引擎。

![GitHub 热门项目 scriptc：将 TS/JS 编译为原生产物](https://opengraph.githubassets.com/18864298bfb962976f6f84dc6a049ac103d6b24ee6705a5f2cf4f59aae0a94d9/vercel-labs/scriptc)

scriptc 使用 TypeScript 编译器进行解析和类型检查，可输出类型化 IR、可读 C、文本 LLVM IR、原生汇编和对象文件。

项目还支持生成原生可执行文件与 WebAssembly 模块，覆盖 macOS、Linux、Windows 及 WASI Preview 1。

项目要求 Node.js 24 或更高版本，部分编译模式依赖平台工具、链接器、SDK/sysroot 或 C 编译器。

[查看原文](https://github.com/vercel-labs/scriptc)

## HydraDB 发布原生支持对象存储的分布式图数据库 {#news-8}

> **HydraDB** 是一款使用 Rust 编写、原生支持对象存储的分布式图数据库，支持具有快照一致性的 OpenCypher 查询。

![HydraDB 发布原生支持对象存储的分布式图数据库](https://opengraph.githubassets.com/de567da85da324d43c257239b967b14874fc9137ed4d15fe94c53ba28a9bf7d4/hydra-db/hydradb)

HydraDB 使用 SlateDB 提供持久化图存储，并支持 GraphBLAS 遍历、兼容 Neo4j 的 Bolt 连接和 HTTPS 查询 API。

S3 兼容对象存储是 HydraDB 的持久化事实来源，计算资源与存储相互分离。

项目将计算划分为数据节点（`graph-node`）和索引器（`graph-indexer`）两类独立角色。

数据节点负责查询和规范变更，索引器在后台构建不可变遍历索引；应用可通过 Bolt 5.x、类型化 JSON 或流式 NDJSON API 接入。

[查看原文](https://github.com/hydra-db/hydradb)

> OpenAI应用研究负责人Boris Power表示，公司80%至90%的研究正面向GPT 7、GPT 8及更高版本。该比例为其个人表述，原文未提供独立核实信息。

## 高盛预计五大科技公司2027年AI基建投资达1.2万亿美元 {#news-20}

> 高盛预计，亚马逊、Alphabet、微软、甲骨文和Meta到2027年将合计投入1.2万亿美元建设人工智能基础设施。该预测投资额较今年水平高出50%以上。

![高盛预计五大科技公司2027年AI基建投资达1.2万亿美元](https://the-decoder.com/wp-content/uploads/2026/09/hyperscaler_ai_investment.png)

高盛表示，按占国内生产总值的比例衡量，这轮投资周期可能成为自19世纪铁路建设以来规模最大的一次。

电力、劳动力和存储芯片方面的瓶颈，可能减缓人工智能基础设施投资的推进速度。

1.2万亿美元是高盛对2027年的预测，实际投资规模仍可能受到相关供应和资源限制影响。
