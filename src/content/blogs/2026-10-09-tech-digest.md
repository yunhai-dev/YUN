## 阿波罗11号软件先驱玛格丽特·汉密尔顿逝世 {#news-1}

> 曾领导 NASA 阿波罗计划机载飞行软件开发的玛格丽特·汉密尔顿于上周去世，享年90岁。她被认为创造了“软件工程”这一术语。

汉密尔顿在20世纪60年代领导了 **NASA** 阿波罗计划机载飞行软件的开发，被认为是阿波罗计划成功的重要贡献者。

她于1936年出生于印第安纳州 Paoli，1958年毕业于 Earlham College，获得数学学位并辅修哲学。

汉密尔顿于2016年获得总统自由勋章。2017年，她被制作成“Women of NASA”乐高套装中的一个乐高人偶。

## Docker Agent 支持用 YAML 构建和运行多智能体应用 {#news-10}

> Docker Agent 是由 Docker Engineering 开发的 AI Agent 构建与运行工具，可作为 Docker CLI 插件通过 `docker agent` 命令使用。

![Docker Agent 支持用 YAML 构建和运行多智能体应用](https://opengraph.githubassets.com/f894e62c6ece0dd3ee9c6ed253d6dca1fd5d11ccc65e714d0fded9a170c128be/docker/docker-agent)

用户可通过声明式 YAML 配置创建和运行 AI Agent，无需编写代码，并支持多 Agent 架构、任务委派和内置工具。

Docker Agent 支持本地或远程 MCP 服务器，项目文档列出 OpenAI、Anthropic、Gemini、AWS Bedrock 等模型提供方。

项目提供可插拔 RAG 能力，支持 BM25、嵌入、混合搜索和重排序，并可将 Agent 推送至 OCI Registry。

文档要求使用 Docker Desktop 4.63 或更高版本，也支持通过 Homebrew、GitHub Releases 等方式安装 `docker-agent`。

[查看原文](https://github.com/docker/docker-agent)

## Microsoft 开源 MXC：面向不受信任代码的沙箱执行系统 {#news-13}

> Microsoft eXecution Container（MXC）是一套用于运行不受信任代码的沙箱执行系统，支持 Windows、Linux 和 macOS。项目提供统一隔离模型与多语言 SDK。

![Microsoft 开源 MXC：面向不受信任代码的沙箱执行系统](https://opengraph.githubassets.com/2ad3130c79308231e55de5fbf7a73ea001a9d0fe804eba5a9310a6d9c2d016fc/microsoft/mxc)

MXC 提供 Rust、.NET 和 Node 类型化 SDK，并支持 ProcessContainer、Windows Sandbox、LXC、Bubblewrap、Seatbelt 等隔离后端。

项目还支持 MicroVM（Nanvix）、Hyperlight、IsolationSession 和 WSLC 等后端，其中部分后端被标注为实验性功能。

MXC 可配置文件系统、网络、剪贴板、显示和 GUI 访问策略，并支持持久化容器的创建、启动、执行、停止和取消。

Windows、Linux、macOS 的默认后端分别为 processcontainer、bubblewrap 和 seatbelt，可用后端取决于运行平台。

[查看原文](https://github.com/microsoft/mxc)
