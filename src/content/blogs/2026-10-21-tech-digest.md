## Omnigraph推出面向对象存储的原生图数据库 {#news-7}

> GitHub 项目 **ModernRelay/omnigraph** 被描述为面向对象存储的原生图数据库，支持分支和类型化本体。项目将图遍历、向量检索和全文检索等能力整合到一个运行时中。

![Omnigraph推出面向对象存储的原生图数据库](https://opengraph.githubassets.com/8d7fad8a58e7b730dde3f3642b32b5568fbc4fbf6e53b3dba8dc801f850324ab/ModernRelay/omnigraph)

Omnigraph 提供统一检索引擎，融合图遍历、向量近似最近邻检索、全文检索和倒数排名。项目还支持类似 Git 的工作流，包括按代理或任务创建分支、三方合并以及对整个图进行时间旅行。

项目使用 `.pg` schema 声明节点类型、边类型、键和约束，并在每次写入时执行这些约束。`cluster.yaml` 可声明图、模式、存储查询、嵌入提供商和策略。

`cluster plan` 用于预览配置，`cluster apply` 用于收敛配置。项目还支持服务器端 Cedar 策略、承载令牌认证、服务器解析的操作者身份和审计跟踪。

数据以开放且版本化的 Lance 格式存储，支持本地磁盘及 S3 兼容存储；页面列出的存储选项包括 RustFS、MinIO、AWS S3、R2、GCS，以及预览中的 Azure。

[查看原文](https://github.com/ModernRelay/omnigraph)

## Impeccable为AI编程代理提供前端设计指导 {#news-8}

> GitHub 项目 **pbakaus/impeccable** 面向 AI 编程代理提供设计指导工具，包含 1 个技能、24 个命令和实时浏览器迭代功能。项目还提供 61 条面向 AI 生成前端设计的确定性检测规则。

![Impeccable为AI编程代理提供前端设计指导](https://opengraph.githubassets.com/f3008fa568679ca647bda82fe4b4234fabca44adf69589f5f0d072ddc70146e4/pbakaus/impeccable)

项目建议从项目根目录运行 `npx impeccable install`，再在 AI 编程工具中运行 `/impeccable init`。该命令会将受众、目的、运行环境、约束、语气和证据等产品事实记录到 `PRODUCT.md`。

Impeccable 提供共享设计词汇，并包含 `polish`、`audit`、`critique`、`distill`、`animate`、`bolder` 和 `quieter` 等命令。

项目设计目标之一，是减少 Inter 字体、紫蓝渐变、嵌套卡片，以及彩色背景上的灰色文字等重复出现的界面模式。

页面关于“61 deterministic detector rules plus LLM-only critique”的后续功能说明未完整展示，因此相关细节暂不明确。

[查看原文](https://github.com/pbakaus/impeccable)

## 8个TLS中间证书私钥薄弱引发互联网安全警戒 {#news-11}

> 安全人员发现 8 个 TLS 中间证书的私钥过于薄弱，相关证书可能被用于伪造受浏览器和应用信任的凭据。

截至周二上午，浏览器厂商以及部分主要应用和编程语言已封锁这 8 个中间证书。它们属于印度证书颁发机构 **eMudhra Limited**。

目前没有证书透明度日志显示这些被攻破的密钥已被恶意使用，但部分互联网系统可能尚未完成更新。

更新 Linux 发行版，以及嵌入式设备和物联网设备等其他互联网基础设施，预计将较为困难且耗时。

发布在 `emudhra.we-have-a-problem.com` 的非正式通告，使用其中一个 eMudhra 证书的私钥进行了数字签名。

[查看原文](https://arstechnica.com/security/2026/10/the-internet-goes-on-high-alert-after-discovery-of-8-compromised-tls-certs/)

## 麻省理工与洛桑联邦理工研发可水下游动飞行机器人 {#news-20}

> 麻省理工学院与瑞士洛桑联邦理工学院工程师设计了一种能在水下游动并重新飞入空中的机器人。该机器人重量低于300克，已在水箱和日内瓦湖完成相关实验。

这款扑翼空水两栖飞行器（`FAAV`）由中央机身、两片柔性机翼和可操纵尾翼组成，机身内置电池与防水电动机。

电动机通过曲轴驱动机翼按预设频率扑动，机翼采用涂覆疏水纳米颗粒的薄膜制成，以帮助排走水分。

实验显示，中等尺寸机翼效果最好：机翼在水中足够柔软，可减小扑动幅度；在空中又足够坚硬，能够维持飞行。

机器人无需脚即可从水面起飞，约70度俯仰角有助于其跃出水面。研究团队还计划测试转动与扑动机翼，并在复杂环境中评估性能。

## MIT开发可熔化再纺的热塑性纱线 {#news-21}

> 美国人平均每年丢弃约81磅衣物，回收选择有限。**MIT工程师**开发了一种可熔化并重新纺丝的热塑性纱线，旨在减少纺织品废弃物。

这种纱线由两种聚乙烯变体制成，聚乙烯常用于牛奶壶和购物袋。由于两种材料属于同一化学家族，纱线无需拆分即可熔化。

研究团队表示，这种纱线的弹性类似于通常由氨纶和聚酯或尼龙组成的传统弹性纱线。

经过10次熔化和重新纺丝后，这种纱线仍保持与传统线材相当的强度和柔韧性。

研究人员希望未来聚乙烯衣物可进入回收体系，但这一循环纺织经济仍属于设想。
