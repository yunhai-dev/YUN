## 组件短缺持续 新电脑价格短期内难以下降 {#news-1}

> The Verge 报道，当前内存与组件短缺被业内称为"RAMaggeddon"，多家公司已宣布涨价，新购电脑的成本压力短期内难以缓解。

![组件短缺持续 新电脑价格短期内难以下降](https://platform.theverge.com/wp-content/uploads/sites/2/2026/03/268408_Apple_MacBook_Air_15_M5_laptop_ADiBenedetto_0020.jpg?quality=90&strip=all&crop=0,0,100,100)

**Valve** 本周公布 **Steam Machine** 售价，起步价 1049 美元，存储为 512GB，约为六年前 **PS5** 上市价的近两倍。

The Verge 测试显示 **Steam Machine** 性能与 **PS5** 相当，但售价已显著偏离以往的主机定价区间。

报道指出，**Apple**、**Microsoft** 等多家公司已因组件短缺宣布涨价。

文章认为，短期内整机价格不太可能下降，消费者正面临一个并不友好的换机窗口。

## GitHub 热门项目：grafana/loki {#news-14}

> **Loki** 是由 **Grafana** 维护的开源日志聚合系统，设计灵感来自 Prometheus，主打低成本与高可扩展。

![GitHub 热门项目：grafana/loki](https://opengraph.githubassets.com/734b73644a740bdcfcb702851b4ce4f891c8184f8790c6b1ed5d4e9ded21ecd2/grafana/loki)

仓库在 GitHub 上拥有 28.4k Star 和 4k Fork，默认分支为 `main`。

Loki 不索引日志全文，而是为每条日志流索引一组标签以降低成本。

Loki 原生支持 **Grafana**（需 `v6.0` 以上），特别适合存储 Kubernetes Pod 日志。

日志栈由三部分组成：**Alloy**（采集）、**Loki**（存储查询）与 **Grafana**（展示）。

**Alloy** 已取代 **Promtail**，后者被视为功能完成，后续开发转向 Alloy。

[查看原文](https://github.com/grafana/loki)
